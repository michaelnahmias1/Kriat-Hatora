# נשמת כל חי — הקלטת כיול לשירה (תפילה, טקסט חופשי)

הקלטה אמיתית ראשונה של חזנות שעברה במסלול "טקסט חופשי" אחרי פריסת שלב 1
(PLAN_TEFILA.md), והסנכרון שחזר ממנה היה גרוע מאוד. **בעל הפרויקט אישר
לשמור את ההקלטה במאגר** לצורך כיול ובדיקות חוזרות של מסלול התפילה והשירה
(פרופיל "שירה", טוקן הכוכב, שם ה׳ עם תחיליות).

## הקבצים

| קובץ | מה זה |
|---|---|
| `nishmat.m4a` | ההקלטה (122 שניות): חזן שר באירוע חי. אודיו רציף, בלי שתיקות, חזק לאורך כל ההקלטה |
| `text.txt` | הטקסט כפי שהודבק בלשונית "טקסט חופשי" — מדויק, שורה = יחידה |
| `received_v1.srt` | הכתוביות שהמערכת החיה החזירה (לפני תיקון שם ה׳ עם תחיליות — `לה'` לא מופה אז) |
| `ground_truth.json` | נקודות האמת שבעל הפרויקט סימן בהאזנה |
| `results.md` | האבחון, טבלת הניסויים וההמלצה לתיקון |
| `asr/` | תמלולים שמורים (כמו בענן / בלי vad_filter) — ל-`--asr-json` |
| `local_best_e19.srt` | הפלט הטוב ביותר מהניסויים (לא של הקוד במאגר) |

## נקודות האמת (ground_truth.json)

- **0–12 שניות:** הקדמה מדוברת שאינה בטקסט (הפסקה קצרה בסביבות 10–11).
- **12.0:** מתחילה השירה של "כִּי לה' הַמְּלוּכָה" (שורה 1).
- **~57:** החזן *אומר* את שם הניגון שבו הוא משתמש — לא בטקסט.
- **~58.0:** מתחיל "נִשְׁמַת כָּל חַי" (שורה 4).
- המילה שבסוגריים `(מֶלֶךְ)` **נאמרה** בפועל.

## הרצה מקומית (CPU)

```
python tools/run_local.py --audio samples/nishmat/nishmat.m4a \
    --text-file samples/nishmat/text.txt \
    --ground-truth samples/nishmat/ground_truth.json \
    --compare-srt samples/nishmat/received_v1.srt
```

דורש סביבה עם torch/torchaudio, faster-whisper, silero-vad ו-uroman, ואת
המודלים (ivrit-ai ו-MMS_FA) — ראה התיעוד בראש `tools/run_local.py`.

התיקייה `samples/` אינה חלק מהאתר ומוחרגת ב-`.vercelignore`.
